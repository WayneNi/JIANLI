## 技术细节

### pdfjs-dist 问题分析
- Next.js 16 (Turbopack) 服务端环境对 worker 支持有限
- 尝试过的方案:
  1. CDN worker URL - 失败 (ESM loader不支持https协议)
  2. 本地文件路径 - 失败 (模块加载失败)
  3. Data URL - 失败 (base64过大)
  4. pdf-parse v2 - 失败 (worker setup失败)
  5. pdfjs-dist v3 - 失败 (Worker加载失败)
- **最终方案**: 子进程解析 (scripts/parse-pdf.js)
