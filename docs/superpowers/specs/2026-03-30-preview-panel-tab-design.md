# 优化预览面板 - 标签式导航设计

## 1. 概述与目标

### 问题描述
当前"优化预览"面板存在信息密度过高、版块过长、文字高度密集的问题，用户阅读体验差，容易产生视觉疲劳。

### 设计目标
- 降低单屏信息密度，提升可读性
- 保持信息完整不丢失
- 优化视觉层次和美观度

---

## 2. 解决方案

采用**标签式导航**设计，将内容按类型拆分到不同标签页中，用户按需切换查看。

---

## 3. 详细设计

### 3.1 整体布局

保持现有三栏布局不变：
- **左栏**（col-span-4）：上传区 + JD输入 + 提示
- **中栏**（col-span-4）：优化预览（**改造为标签式**）
- **右栏**（col-span-4）：下载、求职信、面试题

### 3.2 标签栏设计

**5个标签（使用 Lucide 图标）：**

| 标签 | 图标 | 显示内容 |
|------|------|----------|
| 摘要 | FileText | 个人信息 + 简介 + ATS概览卡片 |
| 工作经历 | Briefcase | 工作经历列表（STAR高亮） |
| 技能&教育 | Award | 技能徽章 + 学历信息 |
| ATS评分 | BarChart2 | 详细评分 + 问题列表 |
| 优化建议 | Lightbulb | JD匹配度 + 技能缺口 + 行动方案 |

> **注意**：图标使用 Lucide React，与项目现有图标系统保持一致。

### 3.4 交互行为

| 交互 | 行为 |
|------|------|
| 标签切换 | 即时切换，无加载延迟 |
| 默认激活 | 打开时默认显示"摘要"标签 |
| 活跃指示 | 活跃标签底部有颜色指示条（渐变紫色） |
| 滚动行为 | 每个标签内容独立滚动，不影响标签栏 |
| 跳转链接 | 摘要页的ATS卡片可点击跳转对应标签 |
| 内联编辑 | 每个可编辑区块有独立编辑按钮，编辑状态仅影响当前区块 |

### 3.5 流式更新行为

| 阶段 | 标签显示 |
|------|----------|
| parsing | "摘要"标签显示骨架屏，加载动画 |
| analyzing | "摘要"标签显示 "正在分析..." |
| suggesting | "优化建议"标签高亮提示新内容 |
| optimizing | "工作经历"、"摘要"标签依次更新内容 |
| formatting | 所有标签内容稳定 |
| completed | 所有内容加载完成，标签均可交互 |

**骨架屏规格：**
- 摘要标签骨架：头像圆形 + 两行文字段落 + 三张ATS卡片
- 工作经历骨架：2个卡片形状，模拟经历条目
- 技能&教育骨架：技能徽章占位 + 教育卡片

### 3.6 内联编辑行为

**编辑触发：** 每个可编辑区块（摘要、工作经历中的描述、技能列表）右侧有编辑图标按钮。

**编辑状态管理：**
- 进入编辑：点击编辑按钮，该区块变为输入框/文本域
- 取消编辑：点击"取消"按钮恢复原内容
- 保存编辑：点击"保存"按钮，更新内容并退出编辑模式
- 跨标签编辑：切换标签时自动保存当前编辑内容

**编辑与流式更新冲突处理：**
- 用户正在编辑时收到流式更新 → 延迟更新直到用户完成编辑
- 或弹出提示："检测到新内容，是否应用？"

### 3.7 空状态与边界状态

| 状态 | 显示内容 |
|------|----------|
| 无简历上传 | 显示上传引导卡片 |
| 正在优化 | 显示流式进度 + 骨架屏 |
| 优化完成 | 正常显示所有标签内容 |
| 优化失败 | 显示错误提示，提供重试按钮 |
| 某标签内容为空 | 显示"暂无内容"占位 + 相关操作引导 |

### 3.8 移动端适配

| 断点 | 适配策略 |
|------|----------|
| < 640px | 标签栏水平滚动，触摸目标 ≥ 44px |
| 640-1023px | 标签栏两行或缩小标签文字 |
| ≥ 1024px | 完整5标签显示 |

**触摸交互：**
- 标签切换：触摸即切换，无需点击确认
- 长按标签：无特殊行为
- 内容区域：可上下滑动查看

### 3.9 样式规格

| 元素 | 样式规格 |
|------|----------|
| 标签栏背景 | `bg-slate-50` |
| 活跃标签 | 渐变背景 `from-indigo-500 to-purple-600`，白色文字 |
| 非活跃标签 | `text-slate-500`，hover时 `text-slate-700` |
| 卡片圆角 | `rounded-xl` |
| ATS卡片 | 渐变背景，数字居中大字显示 |
| STAR高亮 | `from-emerald-50 to-teal-50` 渐变背景 + 绿色左边框 |

## 5. 验收标准

- [ ] 5个标签切换流畅，无明显延迟

- [ ] ATS卡片点击可跳转至对应标签
- [ ] STAR优化内容有明显高亮效果
- [ ] 技能和教育在同标签下分区展示
- [ ] 内联编辑功能正常工作（编辑/取消/保存）
- [ ] 流式更新时正确显示骨架屏和进度状态
- [ ] 空状态显示正确的引导内容
- [ ] 移动端（<1024px）标签可横向滚动，触摸目标 ≥ 44px
- [ ] 原有流式更新功能不受影响
