## 1. MiniMax M2.7 模型切换

### 背景
用户希望将 MiniMax 模型从 `abab5.5s-chat`（旧版）切换到 `MiniMax-M2.7`（新版），以获得更好的 JSON 输出遵循度。

### 问题现象
之前尝试切换时出现错误：
```
Invalid URL (pos 441)
https://minimax-algeng-chat-tts.oss-cn-wulanchabu.aliyuncs.com/ccv2%2F2026-03-24%2FMiniMax-M2.7%2F...
```

**分析**：错误 URL 是 TTS（语音合成）端点，不是聊天 API 端点，说明 `group_id` 参数缺失或无效导致路由错误。

### 代码修改

#### 文件 1: `src/app/api/optimize/route.ts`

**修改 1**：更改模型名称（line 106）
```diff
- model: 'abab5.5s-chat',
+ model: 'MiniMax-M2.7',
```

**修改 2**：添加 `group_id` 参数（line 120）
```diff
+ group_id: process.env.MINIMAX_GROUP_ID,
```

#### 文件 2: `.env.local`

**添加配置**：
```

MINIMAX_GROUP_ID=your_group_id_here
```

## 2. 调试过程：TTS URL 错误根因定位

### 问题
用户反馈"无法生成简历改善建议"，浏览器显示 TTS URL 错误。

### 根因分析
1. 检查 `.env.local` 发现 `MINIMAX_GROUP_ID=your_group_id_here` 是**占位符**，不是真实值
2. 无效的 `group_id` 导致 MiniMax API 将请求路由到 TTS 端点
3. 确认 `route.ts` 中已正确添加 `group_id` 参数引用

### 解决方案
1. 询问用户是否有有效的 Group ID
2. 用户确认 Group ID：`2031666937401971354`
3. 更新 `.env.local`：
```
MINIMAX_GROUP_ID=2031666937401971354
```
