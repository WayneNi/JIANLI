## 1. 问题诊断：简历优化生成到一半失败

### 问题描述
用户反馈点击"开始优化"后，右边预览面板内容生成到一半就消失了，无法完成优化。

### 诊断过程

1. **确认症状**：通过 Playwright 浏览器自动化测试，观察到：
   - 优化按钮点击后，PreviewPanel 显示"正在应用 STAR 法则优化..."
   - 约 1-2 秒后状态消失，面板恢复"等待上传简历"
   - 浏览器控制台显示 402 Payment Required 错误

2. **API 层面分析**：
   ```
   POST /api/optimize
   Response: 402
   Body: {"error":"积分不足，需要 10 积分，当前剩余 0 积分","code":"NO_CREDITS",...}
   ```
   API 本身返回了 402 错误，说明在 `reserveCredits` 阶段就已经失败了。

3. **根因分析**：
   - 新注册用户 `credits = 0`，应该使用免费额度（月均 1 次）
   - `reserveCredits` 中免费额度检查逻辑：
     ```typescript
     const shouldReset = isNewMonth(user.freeResetDate)
     if (shouldReset || user.freeUsageCount < 1) {
       // 应该允许使用免费额度
     }
     ```
   - 但实际测试中，免费额度没有被正确应用，返回了 402 而非免费配额

4. **临时缓解措施**：
   - 增加 `max_tokens`：4096 → 8192（所有 3 处调用）
   - 增强 `parseAIResponse` 的 JSON 解析鲁棒性（增加 4 种策略处理截断响应）

### 实际根因
新注册测试用户（`test-claude-1234@example.com`）积分余额为 0，且免费额度逻辑未生效。

**解决方案**：给用户账户充值积分或修复免费额度逻辑。

## 4. 发现的项目信息

### NextAuth Session 问题
- NextAuth session token 默认不设置 `httpOnly: false`，导致 `document.cookie` 无法读取
- `getServerSession(authOptions)` 在 API Route 中可以正确读取 session
- `page.evaluate()` 中直接 fetch API 时没有携带 session cookie

### Prisma Client 问题
- pnpm 安装的 `@prisma/client` 无法通过 `node -e "require('@prisma/client')"` 直接引用
- 原因：`PrismaClient` 需要通过 `$generate()` 生成编译后的客户端
- 正确方式：通过 `pnpm prisma studio` 或 API Route 内部调用

### Prisma Schema（用户相关字段）
```prisma
model User {
  credits         Int             @default(0)    // 当前积分余额
  isLifetime      Boolean         @default(false) // 是否终身会员
  freeUsageCount  Int             @default(0)    // 当月已使用免费次数
  freeResetDate   DateTime        @default(now()) // 免费额度重置日期
}
```

## 5. 待解决问题

### 问题 1：免费额度未生效
**现象**：`freeUsageCount = 0` 的新用户无法使用免费优化
**可能原因**：
- `freeResetDate` 初始值可能是 `now()`，但 `isNewMonth()` 判断可能有问题
- 或 `freeUsageCount < 1` 条件判断有逻辑漏洞

**下一步**：检查 `isNewMonth()` 函数逻辑，确认免费额度判断条件

### 问题 2：402 错误时前端状态混乱
**现象**：优化过程中 API 返回 402，前端显示"等待上传简历"而非"积分不足"
**原因**：`OptimizeClient` 的 `handleOptimize` 捕获到非 200 响应后直接 throw error，React 状态未正确更新显示错误信息

**下一步**：修改前端错误处理逻辑，在 API 返回 402 时显示"积分不足，请充值"提示

### 问题 3：Playwright 无法直接读取 session cookie
**现象**：测试脚本无法通过 `document.cookie` 获取 NextAuth session
**说明**：这是 NextAuth 默认安全设计，非 bug
